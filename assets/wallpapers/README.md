# Wallpapers

`big-sur-inspired.svg` is original artwork made for this project (a soft
gradient + wave composition in the spirit of macOS Big Sur's default
wallpaper). It's included so `install.sh` has something reasonable to set
out of the box, and it's free to use/modify.

This repo does **not** ship Apple's actual wallpapers or any of the marketing
photography linked in the project README — those are copyrighted and aren't
ours to redistribute.

Want the real thing? If you already have legal access to it (e.g. it's on
your own Mac, or from Apple's site), just drop the image file in this
folder and re-run:

```
./install.sh --only=wallpaper
```

or set it directly via **Settings Manager → Desktop**.
